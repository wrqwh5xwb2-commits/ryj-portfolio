01 / 产品

用自己的话解释问题

这不是自动替人退款的系统。它帮助客服分流问题、查找规定、记录处理。

验收：两分钟演示一次完整工单。
02 / 数据

让新知识立即生效

导入一篇“会员积分规则”，再问兑换比例。观察来源变化，理解数据决定回答边界。

验收：亲手补充一篇规范并查到它。
03 / Python

跟踪一次请求

从浏览器发送问题，走到 app/main.py，再进入 engine.py，最后把结果写进 SQLite。

验收：画出请求路径，说出每层作用。
04 / 机器学习

看懂“训练”和“评测”

在 dataset.py 找到训练与测试样本，用相似词特征理解 TF-IDF，解释分类分数的限制。

验收：添加训练样本，保留测试集，重新评测。
05 / 工程

让错误变得可控

运行自动测试，尝试重复导入、空问题和不合法的工单状态变化，观察错误提示。

验收：说明三个边界情况和处理方法。
06 / 面试

拿真实证据介绍项目

讲清自己修改的内容、测试结果、失败案例和下一步计划。完整资料见 docs 文件夹。

验收：不用照稿回答十个项目问题。
