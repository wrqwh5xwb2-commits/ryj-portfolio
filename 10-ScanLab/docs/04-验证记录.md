## 开发中修复

1. 评测过程中 NumPy 标量不能直接写 JSON：归一化误差转为 Python float 后序列化。
2. 请求期间修改参数可能造成显示值与结果不一致：处理时禁用参数和角点输入；结果变更前禁止下载。
3. Windows 可能把 JavaScript 返回为 text/plain：显式注册 MIME 类型，并由测试验证。
4. 本机停止脚本需要匹配项目解释器完整路径：启动脚本使用绝对解释器路径。
