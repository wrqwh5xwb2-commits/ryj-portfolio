# 05 · 清远本地特产线上导购与数据分析系统

**角色**：组长（团队 3 人）｜ **时间**：2026 ｜ **类型**：课程项目

## 问题
为清远本地特产搭建线上导购平台，并对销售/商品数据进行分析可视化，辅助经营决策。

## 方案
- **后端**：Flask 提供商品、导购、数据接口
- **存储**：MySQL 设计商品/分类/销售数据表（MySQL 5.7 环境，含 SQL 兼容性处理）
- **分析**：Pandas 数据清洗聚合 + Matplotlib 可视化报表
- 团队协作：3 人分工，负责任务拆解与进度管理

## 结果
- 完成"导购 + 数据分析"一体化系统，覆盖数据采集→存储→分析→展示全链路
- 担任组长完成团队协调与交付

## 技术栈
Python · Flask · MySQL · Pandas · Matplotlib
