# 06 · 晨达电脑维修官网（真实商业项目）

**角色**：独立全栈 ｜ **时间**：2026-07 起 ｜ **线上**：zhcdkjw.cn

## 问题
为珠海一家电脑维修实体店建设官方网站，要求真实上线、可被搜索引擎收录、合规备案。

## 方案
- **站点建设**：暖色编辑风主题（Noto Serif SC + Bento Grid），7 个 SEO 页面 + sitemap.xml + 结构化数据
- **部署运维**：虚拟主机（DA 面板）+ 腾讯云 CVM + Nginx 配置
- **SEO 工程**：百度主动推送 API、IndexNow 推送、百度站长验证
- **合规**：域名备案流程对接（接入商中资源），页脚版权/备案号规范化

## 结果
- 网站真实上线运行（zhcdkjw.cn），完成商业交付
- 完整走通"建站→部署→备案→SEO"全流程，具备独立接单建站能力

## 技术栈
HTML/CSS/JS · PHP · Nginx · FTP/SSH 运维 · 百度站长 API
