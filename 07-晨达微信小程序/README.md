# 07 · 晨达电脑维修微信小程序

**角色**：独立全栈 ｜ **时间**：2026-08 ｜ **配套项目**：晨达官网（06）

## 问题
为同一维修店开发微信小程序端，与官网内容一致，支持在线预约服务。

## 方案
- 微信原生开发：8 个页面（首页、4 个服务详情、关于、预约、联系）
- **云开发后端**：云函数 `submitBooking`（提交预约）、`getBookings`（查询记录），云数据库 `bookings` 集合
- TabBar 导航 + 统一视觉主题（与官网一致的暖色编辑风）

## 结果
- 小程序功能完整可运行，预约数据云端持久化
- 掌握小程序"前端页面 + 云函数 + 云数据库"Serverless 开发模式

## 技术栈
微信小程序原生 · 云开发（云函数/云数据库）· WXML/WXSS/JS
