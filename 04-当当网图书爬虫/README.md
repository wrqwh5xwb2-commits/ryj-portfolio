# 04 · 当当网图书信息爬虫

**角色**：独立完成 ｜ **时间**：2026-09 ｜ **类型**：课程实训（进阶层）

## 问题
按任意关键字（Python / Java / 人工智能等）采集当当网图书搜索结果，提取商品名称、单价、作者、出版日期、出版社、内容简介六个字段。

## 方案
- `urllib.parse.urlencode` 构造参数化搜索 URL（key + act + 分页参数）
- 列表页提取基础字段，**详情页二级爬取**出版日期与内容简介
- 关键字参数化设计，一次脚本多次复用
- 请求间隔控制 + 异常重试，csv（utf-8-sig）落盘

## 结果
- 多关键字运行验证通过（Python / Java 等），六字段完整
- 掌握"列表页 + 详情页"两级爬取架构，可迁移至任意电商站点

## 技术栈
Python · requests · BeautifulSoup4 · urllib.parse · CSV
