# 03 · 豆瓣 Top250 电影爬虫

**角色**：独立完成 ｜ **时间**：2026-09 ｜ **类型**：课程实训（基础层，满分标准）

## 问题
采集豆瓣 Top250 全部电影的排名、名称、评分、详情、海报五类数据，要求数据完整无乱码、海报全部有效。

## 方案
- requests + BeautifulSoup 解析列表页，分页参数 `start=0..225` 循环 10 页
- 海报批量下载：JPEG 魔数（`\xff\xd8`）校验内容有效性，失败自动重试 3 次
- CSV 结构化存储：`utf-8-sig` 编码解决 Excel 中文乱码
- 合规控制：每页 sleep 1s、标准 UA、遵守 robots 协议

## 反爬对抗（核心技术点）
1. **418 错误**：豆瓣图片 CDN 强制要求 `Referer` 头 → 请求头补齐解决
2. **JS 挑战拦截**：`img9.doubanio.com` 域名整体返回 JS 挑战页（EO_Bot_Ssid）→ 域名轮换 img1/img2/img3 绕过
3. **字段结构变更**：豆瓣"一句话详情"从 `span.inq` 迁移至 `p.quote > span` → 选择器适配 + 空值容错

## 结果
- **250/250 部电影信息采集成功，250/250 张海报下载有效（完整率 100%）**
- 故障排查过程全程记录，形成可复用的反爬对抗经验

Python · requests · BeautifulSoup4 · lxml · CSV
